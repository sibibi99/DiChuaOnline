# Nhạc nền (nhạc có quyền sử dụng)

Bỏ tệp `.mp3` / `.ogg` / `.m4a` / `.wav` vào thư mục này, game tự phát trộn ngẫu nhiên, hết bài sang bài.
Thư mục trống thì game dùng nhạc EDM tự tạo trong trình duyệt (không bản quyền).

**Chỉ bỏ nhạc mình có quyền phát trên live** (nhạc tự sáng tác, nhạc mua giấy phép, nhạc miễn phí bản quyền có ghi rõ cho phép livestream).
Nhạc remix hot TikTok của người khác phát lại trên live sẽ bị TikTok tắt tiếng / đánh gậy / cắt live.

Ép chế độ bằng tham số link nguồn: `?music=synth` (chỉ nhạc tự tạo), `?music=off` (tắt nhạc).
Các tệp nhạc ở đây không đưa lên GitHub (đã chặn trong .gitignore).
